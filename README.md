# シフトマッチ検索

複数の文字列から同じ位置を同じ順序で拾い、各位置に同じ五十音またはアルファベットシフトを適用して、すべての文字列が辞書語になる組を検索する静的Webツールです。

## 主な機能

- `文字列1`・`文字列2`と、追加ボタンで表示する任意の`文字列3`
- 日本語・英語・両者を組み合わせた検索
- 順序つき・重複なしの位置選択
- 拾う文字数の範囲指定
- 五十音・アルファベットのシフト範囲指定
- 濁音・半濁音の独立したシフト列
- 五十音・アルファベットのループ指定
- カンマ区画をすべて通るpick up検索
- シフト対象外の文字がある位置を自動的に検索対象から除外
- 仔豚辞書・一般語辞書・イラスト辞書・英語辞書・ローマ字辞書の複数選択
- 検索結果の並べ替え
- 入力の小書きかなの親文字化、カタカナのひらがな化

小書きかなの親文字化は入力文字の位置計算にだけ使います。辞書側の小書きかなは変更せず、辞書語との照合は元の表記で行います。

五十音順は次の46文字です。

```text
あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろわをん
```

端をまたぐループは初期状態では行いません。「シフトのループを許容」を選ぶと、`ん→あ`と`z→a`のような循環を有効にできます。

## 開発

```bash
node build-dict-data.mjs
node test.mjs
python3 -m http.server 8000
```

辞書は`dict-data.js`として同梱し、公開サイトから外部辞書へアクセスしません。
