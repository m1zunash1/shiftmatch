# シフトマッチ検索

複数のかな文字列から同じ位置を同じ順序で拾い、各位置に同じ五十音シフトを適用して、すべての文字列が辞書語になる組を検索する静的Webツールです。

## 主な機能

- `w_1`・`w_2`、任意の`w_3`
- 順序つき・重複なしの位置選択
- Nの範囲指定
- 非循環の五十音シフト範囲指定
- 0シフト個数の指定
- 仔豚辞書・一般語辞書・イラスト辞書の複数選択
- 検索結果の並べ替え
- 入力の小書きかなの親文字化、カタカナのひらがな化

小書きかなの親文字化は入力文字の位置計算にだけ使います。辞書側の小書きかなは変更せず、辞書語との照合は元の表記で行います。

五十音順は次の46文字です。

```text
あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろわをん
```

端をまたぐループは行いません。

## 開発

```bash
node build-dict-data.mjs
node test.mjs
python3 -m http.server 8000
```

辞書は`dict-data.js`として同梱し、公開サイトから外部辞書へアクセスしません。
